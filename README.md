## 🎯 Objetivo

Reunir em um só lugar anotações, exercícios, projetos e certificados de cada disciplina, versionados com **Git** e publicados no **GitHub**, para acompanhar minha evolução e servir de portfólio público para recrutadores.

## 🗂️ Estrutura do repositório

```text
Bootcamp-I/
├── index.html                      # Página inicial (GitHub Pages) — v1.0
├── assets/                         # CSS e imagens do site
├── 00_Documentacao/                # Planejamento, documentos e slides do Bootcamp I
├── 01_Apresentacao_e_Perfil/       # Perfil profissional
├── 02_Disciplinas_Atuais/          # Uma pasta por disciplina do 1º módulo
│   └── <Disciplina>/
│       ├── Atividades_e_Entregas/
│       └── Anotacoes_e_Resumos/
└── 03_Projetos_e_Certificados/
    ├── Certificados/
    └── Projetos_Praticos/          # Uma pasta por projeto, cada uma com seu README
```

## 🔀 Fluxo de versionamento

- Branch principal: `main`
- Commits pequenos e descritivos, seguindo o padrão: `docs:`, `feat:`, `fix:`, `chore:`
- Versões marcadas com tags (`v1.0`, `v1.1`, ...)
- Novos conteúdos entram por branches (`feat/nome-do-conteudo`) e são unidos via Pull Request
