# 🌐 Página Web do Study Hub

Projeto inicial do repositório: uma página estática publicada com **GitHub Pages**.

🔗 **Online:** https://nicolasvv-ctrl.github.io/Bootcamp-I/

## Descrição
Página de apresentação do Study Hub, com perfil, áreas de interesse, disciplinas do módulo e links de contato.

## Tecnologias
- HTML5
- CSS3
- GitHub Pages (publicação)
- Git / GitHub (versionamento)

## Onde está o código
Os arquivos do site ficam na **raiz do repositório** (`index.html` e `assets/style.css`), porque o GitHub Pages publica a partir dessa pasta.

## Como executar localmente
```bash
git clone https://github.com/nicolasvv-ctrl/Bootcamp-I.git
cd Bootcamp-I
# abra o index.html no navegador
```

## Histórico de versões
